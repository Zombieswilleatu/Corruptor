# Corruptor UI Overhaul — Earmarked

Status: queued immediately after Action Forecast reaches a trustworthy playable integration.

This is a true redesign, not a cosmetic pass. The current interface is a functional prototype and should not constrain the replacement.

Primary goals:
- Redesign information hierarchy around the decisions a player is making now.
- Make board state, hidden/public information, action consequences, and available resources readable at a glance.
- Reduce modal friction and unnecessary text density.
- Give Hunt, Siege, Ward, Development, Castle Maintenance, and commitment flows clear visual identities.
- Integrate Action Forecast as native decision support rather than an attached debug panel.
- Rework card, Castle, Lord, Guard, Sigil, Threat, Soul, Tear, Veil, and turn-status presentation consistently.
- Establish a coherent visual language, spacing system, typography hierarchy, iconography, feedback states, and responsive layout.
- Preserve tactical information while making the game substantially prettier and easier to operate.

Do not begin this overhaul until Action Forecast truth/parity is stable enough that its information requirements are known.
