# U13 Ward Sigils

Ward creates a fresh Sigil in its selected Lord or Castle zone at Commitment
reveal. The next round's automatic Development changes fresh to decaying;
the following round removes it. Warding again replaces the current Sigil.
Lord Ward also lowers that Lord's Threat by one, floored at zero; statless
Humbaba does not acquire a Threat attribute.

This follows playable U12's active flat-Sigil profile (`sigil_flat = true`),
not the older contested-placement rule. Existing combat continues to apply
Fresh 2 / Decaying 1 defense after Guards, strict-greater breaking, and the
Fresh-break Soul reward when the protected target survives. Internal saved
state retains `flipped`; player-facing labels say Decaying. Old Humbaba
preservation is not reintroduced into the U13 Lord overhaul.

SigilFresh.png is supplied image 1; SigilDecaying.png is supplied image 2.
Non-interactive foreground overlays follow the entire Lord group or Castle
guard zone, including layout resizing. Empty/broken/expired states hide them.
The animation menu now includes a Fresh / Decaying / Expired preview with
click-through cards.

Creation and aging emit public events. Hook clocks are validated on save
restore so replay cannot age or create a Sigil twice in one round.

Run `bash Scripts/Sim/run_u13_game.sh <Godot-4.7.2-executable>` for the expanded
11-suite game gate. The two new suites check lifecycle, refresh, Threat,
serialization/replay, both zone overlays, image loading, and native card input.

Local validation uses the available Godot 4.5.1 for simulation checks and the
standalone preview. The board retains its existing 4.7.2 runtime requirement;
its integration gate must run on that pinned runtime.
