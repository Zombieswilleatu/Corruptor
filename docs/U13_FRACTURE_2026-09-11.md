# U13 Fracture on banishment

The user accepted the production-opening gate at 12/12. This checkpoint adds
printed Fracture to the full-game conductor and expands the game gate to 13/13.
The visual exercise boards retain their own profiles; this is the authoritative
gameplay port, with human full-game controls still on the roadmap.

## Rules and sources

Source is the checked-in playable U12 `FractureEngine`, called by
`HuntResolutionEngine` on banishment. U13 uses these printed values:

| Lord | Fracture |
| --- | ---: |
| Orias | 0 |
| Deimos | 0 |
| Valak | 1 |
| Kroni | 1 |
| Kalligan | 1 |
| Gremory | 2 |
| Odradek | 2 |
| Kanifous | 1 |
| Humbaba | 2 |

The banisher can seal `fracture_target: "subjects"` or `"infrastructure"` in a
Hunt order. Other actions cannot include it. Omitting it uses the recovered
capacity heuristic at resolution: choose Infrastructure only when its score is
strictly greater; ties choose Subjects. Random-Legal explicitly samples both
categories without inspecting private opposing cards or predicting random victims.

Every printed point produces one independent hit:

- Subjects rolls equally among the currently eligible Lord Guards, Castle Guards,
  and Marchers groups. Empty groups are excluded and rebuilt after each point.
- A Guard group selects one eligible Guard randomly, reducing its value by 2,
  floored at 1. A value-one Guard is ineligible. It remains the same physical card
  and is not defeated. U13 already projects all deployed Guards publicly.
- A Marcher group selects up to three distinct living owned bodies, across both
  lanes and including waiters. Each loses 1 HP directly, bypassing Armor without
  consuming it. Later points can hit a surviving body again.
- Infrastructure hits the highest-Integrity eligible Castle for 2. Ties use
  physical slot order. Each copy is used once before cycling over survivors.
  Protected construction, Ruined/Profaned structures, and zero Integrity are
  excluded. Reaching zero Ruins the same identity; floor crossings set the usual
  Repair lock.
- Hands and undeployed cards are immune. Current entity ownership determines
  allegiance after Odradek transfers.

## U13 integration

The opt-in `U13_FRACTURE_V1` profile runs from the shared `LORD_BANISHED` reaction,
before the Hunt changes the Breach. Banishment clears ordinary Threat before
reactions. An already absent Lord cannot be banished again. The banishment event
ID is recorded so repeated delivery cannot apply a second Fracture.

Marcher deaths use the shared damage/death boundary with hazard attribution.
Castle ruination emits `CASTLE_DESTROYED` through the current Lord reactions, so
applicable U13 Sifting and Deimos effects still work. Fracture does not itself
grant Siege Souls, combat kill credit, or an additional neutral Tear. Guard
erosion is not a Guard-defeat event.

Keyed RNG uses the banishment identity, point index and selection purpose, with
stable entity ordering. Replaying the same save and seed reproduces the same
victims regardless of registry insertion order. The match policy includes the
new profile; older saves require a new game. Random-Legal advances to V2 because
Hunt orders now choose a category.

Fracture is distinct from current Threat and the U13 summon-payment shortfall.
This port does not replace the verified resummoning/Mark mechanics with the old
U12 return model, and it does not restore stale Fracture debt.

## Verification

The new runner covers all printed values, repeated Guard erosion, private-card
immunity, deterministic replay and reversed entity ordering, distinct Marcher
victims, direct HP and lethal damage, Castle spread and protection, Repair locks,
ruination attribution, default category ties, repeated-event rejection, and both
explicit categories through a real Hunt and full-round JSON replay. Malformed
category and ledger restores reject atomically.

Compatibility validation passed the twelve game simulation suites, plus Orias
resummoning and Mark regressions. The Sigil board gate requires Windows 4.7.2.

Run `bash Scripts/Sim/run_u13_game.sh <Godot-4.7.2-executable>` and expect
`U13 game foundation runners passed: 13/13`. Local simulation compatibility uses
Godot 4.5.1; the Sigil board integration remains pinned to the user's 4.7.2 runtime.
